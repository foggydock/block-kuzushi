# ブロックくずし

ブラウザで遊ぶ、5ステージのブロックくずしです。外部通信・アカウント・保存データは使いません。

[公開ゲーム](https://foggydock.github.io/block-kuzushi/)

## 遊び方

- 「やさしい」はライフ5・幅広のバー・ゆっくりのボール、「ふつう」はライフ3で少し速くなります。
- 指を動かすかマウスを動かしてバーを操作し、画面をタップ／クリックすると発射します。
- 「大」のアイテムはバーを広げ、「♥」はライフを1増やします。
- 別のアプリやタブへ移ると自動で一時停止します。戻ってタップすると、停止時の位置から再開します。発射待ちの場合は、もう一度タップすると発射します。
- ライフがなくなるとゲームオーバー、5ステージを終えると全クリアです。

## 開発と確認

ビルドや依存パッケージのインストールは不要です。

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:8765 を開きます。
Node.js 18以上で、回帰テストを実行できます。

```sh
node test/game.test.js
```

テストはHTMLのスクリプトの写しをVMで実行し、DOM／Canvasを代替します。内部状態への入口はテスト内だけに追加し、公開ページには含めません。30/60/120Hz、角の衝突、硬いブロック、ステージ・ライフ・全クリア、一時停止と再開、アイテム、待機中の描画、2万フレームの自動プレイを確認します。

画面表示は別途ブラウザで確認してください。スマホ幅375pxとPC幅、両難易度、タッチ／マウス、画面離脱後の再開、終了後の再挑戦、縦横回転が確認対象です。120Hz端末での体感やiOSホーム画面起動は実機確認が必要です。
